# Risen ImpExp — аддон Blender для Risen 1

[English](README.md) · **Українська**

Імпорт і експорт моделей, персонажів, анімацій, міміки, колізії та рельєфу **Risen 1** (Piranha
Bytes, 2009, рушій Genome) у **Blender 5.1+**.

> **Стан: бета 0.9.** Кожен файл, який пише аддон, звірено з файлами самої гри (більшість — байт у
> байт, див. *Як це перевірено*), але весь шлях у грі ще не пройдено повністю. Зробіть резервну
> копію гри й повідомляйте, що знайдете.

## Що він уміє

**File → Import** (прямо з архівів `.pak` гри, пошук за назвою в межах категорії):

| Пункт | Файли гри | Що з'являється в Blender |
|---|---|---|
| Risen Model | `._xmsh` + `._xmat` + `._ximg` | меш з текстурами (вершини зварені, шви uv/нормалей збережені) і його колізія — каркасний дочірній об'єкт `<назва>_COL`. Категорії: будівлі, локації, предмети інвентаря, декор і меблі, оточення, дерева й кущі (заглушки SpeedTree), трава й чагарник, вода, службові |
| Risen Character | `._xmac` | скелет (кістки паличками) і меш зі шкінінгом, без анімації; голова людини — окремий меш з дев'ятьма формами обличчя (shape keys: кліпання і вісім положень рота). Категорії: люди — тіло (з вибраною головою) або голова, монстри, анімовані об'єкти, предмети |
| Risen Animations | `._xmot` | анімації тіла на вибраний скелет Risen: одна або ціла категорія — стійка, рух, атаки, захист, діалоги й жести, сидіння, сон, взаємодія, смерть |
| Risen Lip-sync | `._xmot` + `._xsnd` з `infos/` | репліка діалогу на shape keys голови (як дія), її голос у Video Sequencer, кліпання за бажанням; будь-яка з чотирьох мов |
| Risen Collision | `._xcom` | лише колізія, каркасним мешем |
| Risen World Layer | `.lrent` | розставлені об'єкти шару — як оточення, щоб будувати поруч |
| Risen Landscape | `Levelmesh_Landscape_01` | земля острова, щоб змінити рельєф |

**File → Export** (встановити в гру або зібрати пакет мода з `INSTALL.bat` / `ROLLBACK.bat`):

| Пункт | Що пише |
|---|---|
| Risen Model → Mod | `._xmsh`, нові матеріали й текстури, колізію (дочірній `*_COL` або виділені об'єкти `*_COL`, інакше — сам меш), каталоги ресурсів рушія |
| Risen Motion | кліп `._xmot` замість одного з кліпів гри, вибраного за категорією (типово — той, з якого прийшла дія) |
| Risen Actor | `._xmac` — ваш меш на скелеті гри (нова броня, тіла), ваги з груп вершин; голова, експортована окремо, замінює ту голову й зберігає shape keys як форми обличчя, тож губи в діалогах і далі рухаються |
| Risen Landscape | землю, змінену на місці, і сектори колізії під вашою правкою |

Вкладка **Risen** у бічній панелі 3D-вікна має все це, плюс список модів, встановлених з Blender, з
кнопкою «прибрати» біля кожного. Коли вибрано скелет Risen, там же є **риг для анімування**: кольори
й групи кісток, фігури, за які зручно хапати, і IK для рук і ніг (ціль і полюс на кожну кінцівку). Риг
лише додає кістки, які нічого не деформують, тож скелет гри лишається точним: IK спершу вимкнено,
вмикання кінцівки ставить ціль точно в поточну позу, експорт анімації запікає результат, а кнопка
*Запекти* переносить його на кістки гри.

### Де його місце

У Blender створюють *речі*: предмети, будівлі, геометрію цілих локацій, персонажів, анімації,
текстури. Розставити їх у світі (об'єкти, спавни), скрипти й рутини NPC — справа редактора світу.
Тому шар світу приходить у Blender лише як оточення, і нічого тут не пише розстановку об'єктів.

## Встановлення

1. Blender 5.1 або новіший.
2. *Edit → Preferences → Get Extensions → ⌄ → Install from Disk…* → `risen_impexp-0.9.5.zip`
   (зі сторінки Releases).
3. У налаштуваннях аддона вкажіть **Risen game folder** (ту, де лежить `bin\Risen.exe`; шлях Steam
   уже підставлено). За бажанням — папку кешу й папку для пакетів модів.

Zip містить `risen-core.exe` — нативну частину (Windows x64). Більше нічого не потрібно: ні PhysX
SDK, ні допоміжних програм.

Моди, встановлені з Blender, вмикають `NoPhysical=false` у `bin\mountlist_packed.ini` (копія
оригіналу зберігається), щоб гра читала окремі файли. Архіви гри ніколи не змінюються.

## Швидкий старт

- **Замінити меч:** Import → Risen Model → `It_Wpn_BS_RuneSword`. Змініть його, руків'я тримайте в
  початку координат (лезо вздовж +Z у грі, у Blender це +Z вгору). Export → Risen Model → Mod, та сама
  назва, *Встановити в гру*. Запустіть гру.
- **Нова броня:** Import → Risen Character → `Ani_Hero_Armor_Player`. Виліпіть або замініть меш, лишіть
  його прив'язаним до скелета (групи вершин з назвами кісток). Export → Risen Actor, та сама назва.
- **Змінити анімацію:** Import → Risen Character → істота, виділіть її скелет, Import → Risen
  Animations → категорія (скажімо, *Атаки*). Змініть дію, Export → Risen Motion: кліп, з якого вона
  прийшла, вже вибрано.
- **Анімувати вручну:** виділіть скелет, вкладка *Risen* → *Риг для анімування*, увімкніть IK для
  потрібних кінцівок, ставте ключі на цілі `RIG_IK_*`. Далі Export → Risen Motion, як звичайно.
- **Змусити персонажа говорити:** виділіть персонажа, Import → Risen Lip-sync, виберіть репліку (слова
  з її назви, напр. `PC_Hero` — гравець). Програйте з увімкненим звуком.
- **Нова голова:** змініть меш голови (і за бажанням її shape keys), виділіть лише голову, Export →
  Risen Actor з назвою голови.
- **Змінити рельєф:** Import → Risen Landscape, рухайте вершини (добре працює proportional editing),
  не додавайте й не видаляйте жодної. Export → Risen Landscape.

Масштаб: Risen рахує в сантиметрах; аддон імпортує з масштабом 0.01 (метри) і так само експортує назад.

## Обмеження (0.9.3)

- Матеріали нових мешів робляться з шаблонів матеріалів гри: непрозорий, непрозорий зі specular або
  з alpha test (поріг — з підключення Alpha); інших ефектів шейдера немає.
- Скелет завжди береться з актора гри. Замінена голова зберігає ті форми обличчя, для яких є shape
  keys; зміни нормалей у формах не зберігаються (у власних головах гри їх теж немає).
- Ліпсинк імпортується на обличчя; запис нових кліпів ліпсинку поки не підтримується.
- Дерева й кущі — це рецепти SpeedTree, які гра вирощує сама: вони приходять заглушками потрібного
  розміру й вигляду, щоб будувати поруч, і назад не пишуться.
- Колізія пишеться трикутними мешами (без опуклих оболонок). Файли консольних версій (big-endian) не
  читаються.
- Нова модель чи актор з'являється в грі лише тоді, коли щось її розставляє або на неї посилається
  (редактор).
- Перевірено лише ПК-версію Steam/GOG (`risen-core` читає її архіви `.pak`).

## Як це перевірено

Без запущеної гри тестом слугують файли самої гри (`cargo test` із заданим `RISEN_GAME`):

- загальний читач/записувач властивостей переписує всі 3 523 меші, матеріали й текстури байт у байт;
- кожен запис каталогів ресурсів рушія (меші, матеріали, зображення, колізія, анімації) відтворюється
  з його файлу ідентично;
- наш записувач `._xmsh` відтворює байт у байт меш, уже перевірений у грі;
- 635 з 637 файлів колізії (1 087 потоків PhysX) переписуються байт у байт; дерева, межі й масові
  властивості, які рахує наш кукер, збігаються з рушієвими, прапорці опуклих ребер — на 99,99 %;
- усі 106 little-endian акторів переписуються байт у байт; актор, перезібраний через експортер,
  зберігає грані, UV і ваги; кліп проходить гра → Blender → гра з точністю 1e-6;
- шлях рельєфу дає ті самі байти, що й правка висот, яка вже працює в грі;
- форми обличчя всіх 14 голів читаються й переписуються з точністю до 16-бітного кроку; голова,
  перезібрана через експортер, зберігає всі дев'ять; рука, зрушена через IK, повертається з
  експортованого кліпу туди, куди її поставили.

## Збірка з вихідного коду

```sh
cd core && cargo build --release          # risen-core.exe
BLENDER=/path/to/blender.exe tools/build_release.sh   # dist/risen_impexp-<версія>.zip
```

Для розробки зробіть junction `addon/risen_impexp` у папку аддонів Blender; аддон сам знайде
`core/target/release/risen-core.exe`. Тести: `RISEN_GAME="C:\...\Risen" cargo test --release`.
